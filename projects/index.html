Dataquest

Next.js · TypeScript · FastAPI · PostgreSQL · Gemini API

An AI-assisted form builder with natural-language generation and manual editing. Generated schemas are validated with Pydantic before persistence. Supports form versioning, public submissions, response analytics, and CSV exports, with JWT authentication, refresh-token rotation, ownership checks, and CSRF protection.

AsteroidDB

Rust · LSM trees · Storage engine

An embedded key-value storage engine with memtables, SSTables, and compaction. Implements write-ahead logging, atomic write batches, and crash recovery, with Bloom filters and block caching to accelerate reads.

Benchmarked across 1 million keys with asynchronous writes: 116K sequential writes/sec, 119K random writes/sec, and 7.48M sequential reads/sec.

Subspace

Rust · Tokio · Distributed systems

An IPFS-inspired peer-to-peer storage prototype using SHA-256 content addressing, chunking, and Merkle DAGs for file reconstruction. Implements Kademlia-style lookups with XOR-distance routing and k-buckets, asynchronous TCP block exchange, mDNS discovery, bootstrap peers, and filesystem-backed storage.

Aloha

C++ · LLVM · CMake

A native compiler for a statically typed language, from lexing and parsing through symbol binding, type resolution, and a custom typed intermediate representation to LLVM IR. Supports structs, enums, arrays, references, and module imports, with compile-time checks for mutability, function arguments, exhaustive pattern matching, and missing return paths. Includes an arena-backed C runtime for allocation, strings, and dynamic vectors.
